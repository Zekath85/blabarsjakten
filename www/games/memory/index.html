Memory

Hur många spelare?

Så spelar man Memory

Målet: hitta flest par. Ett par är två brickor med samma bild.

Din tur: Tryck på en bricka. Den vänder sig. Tryck sedan på en bricka till.

Blev det ett par? Då får du behålla paret och vända två brickor till.

Blev det inte ett par? Då vänds brickorna tillbaka. Nu är det nästa spelares tur. Försök komma ihåg var bilderna ligger!

Vem vinner? När alla par är tagna vinner den som har flest par.

Omgångar: Du väljer hur många omgångar som behövs för att vinna spelet.

Mot datorn: Välj en nivå: lätt, medel eller svår. Datorn kommer ihåg olika mycket.
